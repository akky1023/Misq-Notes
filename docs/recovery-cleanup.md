# 復旧コピーの自動整理

## 設定

検証版の「総合設定 → ノート設定 → ノートの保存先」に「復旧コピーを自動整理」を追加した。初期状態はオフで、外部保存先ごとに有効化する。この設定は保存先をこの端末だけで使う場合専用であり、別端末や別のMisq notesアプリと共有する保存先ではオフにする。保存先を切り替えても別の保存先へ自動で有効設定を引き継がない。

## 整理の条件

- 外部への接続または保存が成功し、端末の同期基準を耐久保存した後に実行する。有効化時にも候補を確認する。
- 未保存の変更、保存先切り替え、外部の世代変更による停止中は実行しない。
- 最新・直前の2世代の参照と、端末の同期基準およびそのバックアップが参照する本文を保持する。
- 連続する2回の確認で未参照だった本文だけを整理する。候補は端末内の`.notes-recovery-cleanup`へ保存し、再起動後にも確認を続ける。候補一覧を読めない場合は削除候補を引き継がず、確認し直す。
- 本文を整理した後、その本文以外から参照されない共有ブロックも同じ方式で回収する。残す復旧本文と表示用`.misq`、他のツールが作った`.misq`コピーが参照するブロックは保持する。
- 1回の削除は本文・共有ブロックの合計で最大32個とし、残りは次の起動・保存で処理する。

対象は`inkdata/.recovery/blob-<SHA-256>`と`inkdata/.blocks/block-<SHA-256>`だけである。現在のノート、世代JSON、名前が一致しないファイル、筆跡本文内の変更履歴、`.regions`キャッシュはこの処理では削除しない。

確定世代が2つ揃わない場合、同じ世代番号の分岐、管理JSONの破損、同期基準と外部最新世代の不一致、保護する本文・ブロックの欠落、削除中のファイル一覧の変化があれば整理を中止する。削除に失敗しても外部へ確定済みの保存を失敗扱いにせず、次回の確認で再試行する。削除は本文を先に、ブロックを後に行う。

これは複数端末で共有する保存先に対する自動回収ではない。別端末のオフライン中の同期基準を収集する仕組みはないため、設定はオフが既定値である。
