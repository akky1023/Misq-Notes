# バッテリー消費の切り分け（2026-11-13）

## 本番 0.6.1 の起動と外部保存

- 本番のコールド起動後、一覧で操作せず約155秒間を採取した。32サンプルの平均CPU使用率はMisq notes 68.4%、MediaProvider 166.6%、ExternalStorageProvider 57.3%。100%は1コア分。
- 本番を停止した8秒後にも、MediaProviderが137〜140%、ExternalStorageProviderが59〜62%だった。ストレージ側の処理が本番のプロセスより長く残る場合がある。再起動直後の負荷だけで、別プロセスのCPU時間をすべて本番に帰属させることはできない。
- 本番が外部ストレージへの永続権限を持つフォルダーの一つで、オブジェクト75,366件、検証ファイル75,365件、コミット333件を確認した。全件列挙、未確認の検証ファイルの読み込み、コミット履歴の検証は別々の工程。
- 本番と現行developの外部同期・保存コードは同一。端末はXiaomi Pad 7。採取時はUSB給電。

- 検証用DocumentsProviderに8,000件（オブジェクト4,000件・検証ファイル4,000件）を置いた。列挙のみ0.87秒、初回列挙と未確認ファイルの検証3.59秒、同じプロセス内の再同期0.87秒。コミットなしのため、コミット履歴の検証と実ファイル本体の転送は含まない。本番のExternalStorageProviderとは実装が異なる。

## 端末内保存の筆記

検証版の専用フォルダーに3,600画を生成し、各試行で同じ45画を約25.6秒かけて追加した。表はアプリプロセスのCPU時間。電力量、GPU負荷、OS側のファイル処理のCPU時間は含まない。

| 条件 | CPU時間 |
| --- | ---: |
| 通常 | 21.99〜22.12秒（3回） |
| 完成済み筆跡を非表示。入力中のInkと用紙は描画 | 19.56〜19.93秒（2回） |
| サムネイル生成を停止 | 21.51秒 |
| 本体の自動保存とサムネイル生成を停止 | 15.26秒 |
| 無操作で24秒 | 1.56秒 |

固定画面で連続筆記する条件では、完成済み筆跡を非表示にするより、自動保存を止めた方がアプリCPU時間の差が大きい。サムネイルは端末内保存では更新要求が途切れるまで待つ。外部保存時の強制生成にはこの結果を適用できない。既定の保存頻度の変更は、未保存データの許容時間と合わせて検討する必要がある。

## 描画・先読み・競合スキャン

- 同じ筆記の別の比較で、端末全体のGPU稼働率は通常23.6%、完成済み筆跡を非表示にした場合17.4%、放置0%。筆記はいずれも約25秒間の19サンプルの平均で、GPU電力への換算は行っていない。
- 同じ3,600画を閉じて開き直した比較では、表示に必要な初期読み込みは両条件とも1,428画。その後通常は749画を先読みして計2,177画になり、先読みを止めた場合は1,428画のまま。閉じる操作から再表示後8秒までのCPU時間は11.40秒と4.78秒。周辺データと描画準備を同時に止めた比較。
- 3,600画の同一内容を持つ作業ファイル12件を用意した。キャッシュが温まった状態で22秒間放置した際のCPU時間はスキャンあり1.43秒、スキャンなし1.44秒。新規競合の取り込みや自動マージはこの比較の対象外。

## 電力の測定範囲

AndroidのBatteryManagerが返した電流は電池の充放電電流で、USBから端末に入る全電力は含まない。ADBから利用できる端末全体の電力レール積算値は確認できなかった。この調査で比較できるのはCPU時間、GPU稼働率、温度。実際の電池消費を比較するには、USBを外し、輝度・リフレッシュレート・筆記操作を揃えて電池の積算値を長めの区間で比較する。

## 外部同期の初回検証を削減

外部同期では一覧を取り、公開・受信する版が参照するオブジェクトの検証ファイルを必要に応じて開くようにした。従来形式のファイルはそのまま利用できる。列挙、参照先の検証、破損・欠落時の扱いは維持する。

同じXiaomi Pad 7の模擬DocumentsProviderで変更前1回と最終版2回を比較した。背景に8,000ファイルを用意し、履歴ありの条件では別途20コミットを追加した。括弧内は検証版プロセスのCPU時間。

| 条件 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 初回、参照なし | 3.281秒（3.896秒） | 0.640〜0.657秒（0.818〜0.846秒） |
| 初回、20コミットの履歴あり | 2.858秒（3.482秒） | 0.813〜1.033秒（0.944〜1.423秒） |
| 同じプロセスで再同期、20コミットの履歴あり | 0.681秒（0.810秒） | 0.709〜0.768秒（0.779〜1.008秒） |

初回の短縮を確認した。一覧に変更がない場合は検証候補の索引を再利用する。再同期でも外部保存先の全件列挙は行う。模擬保存先での比較であり、本番約15万件の同期時間と消費電力は未計測。
