## ログの読み方

- `touch` は `dispatchTouchEvent`、`generic` は `dispatchGenericMotionEvent`、`key` は `dispatchKeyEvent` で観測したものです。
- `action` はpointer indexを含む生値、`actionName` はAndroidの文字列表現、`actionIndex` は操作対象ポインタのインデックスです。
- 標準の `BUTTON_STYLUS_PRIMARY` は `0x20`、`BUTTON_STYLUS_SECONDARY` は `0x40` です。異なるビットが届いた場合も生値を保存します。ビットからFocus Penの物理ボタンを推測せず、操作と照合してください。
- `pressedButtons` / `releasedButtons` は同じdeviceId・sourceで前に観測したbuttonStateとの差分です。`firstButtonObservation=true` は基準値の初回取得を示します。
- `actionButton` は明示的なボタンイベントの対象です。MOVE中の差分と両方を確認します。
- `history` はバッチ配送された過去の座標・筆圧です。`omittedHistory` が0以外なら古いサンプルを省略しています。
- `receivedUptimeMs - eventTimeMs` はアプリへの配送時点までの時間差で、画面表示までの筆記遅延を示しません。
- JSONの `buttonSignalEvents` はボタンに関係するイベント数で、物理ボタンの押下回数ではありません。
- JSONには入力デバイス名・descriptor・OSビルド情報を含みます。外部共有時には内容を確認してください。

| 項目 | 判定／根拠 |
| --- | --- |
| ペンの接触入力を取得できたか | 取得できた。STYLUS、座標、DOWN/MOVE/UPを確認 |
| pressureの変動を取得できたか | 取得できた。筆圧.jsonで接触中約0.000122〜0.480039 |
| 下ボタンの押下／解放に対応するイベント | KEYCODE_PAGE_DOWN（93）、scanCode=109 |
| 上ボタンの押下／解放に対応するイベント | KEYCODE_PAGE_UP（92）、scanCode=104 |
| 独立ボタンの押下／解放に対応するイベント | KEYCODE_BUTTON_6（193）、scanCode=189 |

| 消しゴム割り当てに使う入力方式 | Focus Pen由来のKeyEventで接触前からの保持状態を管理する。筆記途中からの押下に依存しない。機能割り当て・消去動作はPhase 2で検証 |

イベントがない場合は「この端末・OS設定・操作条件ではActivityに通知されなかった」と記録します。標準APIで不可能と断定せず、OSのボタン設定、ペアリング、ホバー範囲、KeyEventを再確認します。次の調査では公開情報と、取得可能な端末ログを照合し、非公開APIや特権権限を前提にしません。
