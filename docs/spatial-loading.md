# 位置別ブロックの遅延読み込み（2026-11-03、検証版）

後続の保存側の変更は[位置別ブロックの変更記録](block-change-tracking.md)を参照。

## 初期表示

筆跡の開始Y座標を1000論理ピクセルで区切って所属を決め、表示範囲と前後の余裕に必要な位置別ブロックだけを取得・復元する。
筆跡の上下端も記録するため、別の帯から画面内へ伸びている長い筆跡も取得対象になる。
1本の筆跡は切断せず、所属ブロック1か所に保存する。描画順は従来の操作IDで保持し、帯の順番へ並べ替えない。
同じ帯が大きい場合は約4 MiBを目安に複数のパックへ分ける。単独の大きな画像・筆跡は分割しない。

開いた時点では全文の内部 `.misq` を取得しない。表示領域を復元した時点で画面を開き、その後は画面に近い未読パックから順に、残りすべてをバックグラウンドで取得・復元する。画面を移動した場合は移動先を優先する。
パックを1つずつ読み、筆跡の形状生成は保存・画面移動が使うリポジトリのロック外で行う。画面への追加は128本以下に分け、筆記・選択などの操作中は取り込みを待つ。
バックグラウンド読み込みは編集を禁止するbusy状態にせず、既存の編集・削除・Undo/Redo履歴と採番を保持する。すでに編集・削除したIDは古いパックから追加し直さない。
ノートを閉じる・切り替える際は読み込みを中断し、古い読み込み結果を別のノートへ追加しない。読み込みに失敗した場合はエラーを表示し、再試行から読み込みを再開できる。
読んでいない筆跡も一覧の参照として保持し、操作IDの採番と画面の総筆跡数に含める。
移動先の表示準備が必要な間はその範囲を編集する操作を待つ。それ以外のバックグラウンド読み込み中は、小さな読み込み表示だけを出す。

## 外部の配置と正本

```text
inkdata/
  <UUID>.misq                  既存の表示用ノート／1 MiBブロック管理ファイル
  .blocks/                     全文の確実な復元に使う従来の保存ブロック
  .recovery/                   従来の確定世代・復旧コピー（保持方針は変更しない）
  .regions/
    index-<ノート全文SHA-256>     表示位置・用紙・全筆跡参照・位置・パック参照
    region-<構成SHA>-<本文SHA>    位置別にまとめた筆跡本文
```

`.regions` は確定済みノートから再生成できる読み込み用データで、正本は従来の確定世代と復元可能な本文。
位置別の本文を別途持つため外部容量は増える。今回は古い位置別データ・未使用ブロック・recoveryの整理や軽量化を行わない。
外部フォルダの移動・同期・バックアップは隠しディレクトリを含めた `inkdata` 一式で扱う。

索引はノート全文ハッシュに対応させ、本文のSHA-256を持つ。各パックは筆跡ごとのサイズ・SHA-256と、パック全文のSHA-256を検証する。
キャッシュがない・不完全・破損している場合は通常の全文読み込みへ戻り、空のノートとして扱わない。
全文読み込みで筆跡の位置情報を準備し、外部保存の完了時に位置別データを生成する。生成に失敗しても確定済みノートは失わない。

既存ノートには位置の索引がないため、最初は一度全文を読み込む必要がある。保存を完了して閉じた後、以後のオープンで位置別読み込みを使える。
未保存の内部作業ファイルが残っている場合も、その作業を優先して通常の読み込みを使う。

## 部分編集の保存と復旧

保存する全筆跡参照は「まだ読んでいない元の参照」と「読み込んだ範囲の現在の筆跡」を合わせて作る。
読み込んだ後に削除したIDは再取得の対象から外し、古いパックから復活させない。
筆跡を移動すると新しい開始位置・上下端を保存し、元の帯と移動先のパック構成を更新する。

正本への保存・競合統合は従来の全文MISQ0002経由で行うため、最初の保存時には未取得の本文を取得する。
その取得より前に、編集済みの本文・全参照・位置情報を内部の `notes/.partial-<UUID>` へ耐久保存する。
取得に失敗しても記録を保持し、再試行・再起動後に元の未読本文と合わせて保存する。
保存先切り替え時にも部分編集を復元し、明示的なノート削除は削除記録を優先して復活させない。

全体の書き出し・空白挿入など、ノート全体を必要とする操作では残りを読み込んでから実行する。全体プレビューはバックグラウンド読み込みの完了後に組み立て、プレビューのために編集を止めない。
部分読み込みが編集としてUndo履歴に記録されることはなく、採番済みの新しいIDも変更しない。

## 計測

実ノートを読み取り専用で複製し、専用DocumentsProviderの使い捨て保存先で各1回比較した。
元のノート・外部保存先・recoveryへは書き込まない。

| 方法 | 初期読み込み時間 | 復元した筆跡 | プロバイダー読み取り |
| --- | ---: | ---: | ---: |
| 全文を取得して復元 | 3,356 ms | 8,157本 | 33,193,523 bytes |
| 位置別の初期範囲だけ取得・復元 | 460 ms | 1,296本 | 1,611,757 bytes |

この比較では初期読み込み時間は約86.3%、外部読み取り量は約95.1%減少した。
全文側は取得・全筆跡の復元・位置情報の初回保存を含む。位置別側は位置別データ生成後の索引取得と初期範囲の復元を含み、生成時間を含めない。
最初の画面の周辺（保存済みの上端より500上から2000下まで）を比較対象にした。実際の初期範囲は画面比率と倍率にも従う。
描画やUIレイアウト時間は含まない。各1回のコピーでの参考値であり、ユーザーの実保存先での所要時間を保証する値ではない。
