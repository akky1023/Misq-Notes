# 筆跡の両端の太さ補正

完成した筆跡の描画用コピーで、始端・終端付近の急に細くなる部分だけを補い、太い部分を細くしない。設定項目は設けず、共通描画器を通る画面表示・プレビュー・PNG/PDFに適用する。保存済みの座標・筆圧・時刻・ブラシと、筆記中の低遅延描画は変更しない。

保存された筆圧カーブから各入力点の太さ倍率を求め、始端・終端からブラシサイズ1個分以内の各点を基準に、太さの減少を移動距離の半分までに制限する。両方向から処理し、太い端と周囲の細い部分、細い端と手前の太い部分を、細い側の倍率を増やしてつなぐ。倍率は減らさず、補正後の倍率を元の単調な筆圧カーブで逆変換して描画用筆圧に戻す。

点数や時間でなく筆跡に沿った距離を使う。倍率差は最大1なので、補正の影響は両端から最大でブラシサイズ3個分以内に収まる。3点未満、全長がブラシサイズ2個分未満、筆圧なし、固定幅のブラシ、旧StockBrushesの筆圧ペンは補正しない。

単体テストで太い両端の保持、急な細まりの補完、同一座標、点打ち・短い筆跡、入力密度、描画方向、非線形カーブを検査する。端末テストで保存バイト列と入力属性の保持、原点・長いノートでの適用、細い部分の描画画素の増加と太い両端の保持を検査する。

これは両端の筆圧変化に対する対策である。実際の報告筆跡を使った原因の確定や、長時間の実筆記での見た目の評価は別途必要。
