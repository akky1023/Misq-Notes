# 筆跡の太さ補正

筆圧ペンの急な細まりを、筆記中からInkのブラシ動作で補う。完成後だけ筆圧を差し替える処理は廃止し、筆記中・完成線・再読み込み・プレビュー・PNG/PDFで同じブラシを使う。設定項目は追加せず、保存する座標・筆圧・時刻・筆圧カーブは変更しない。

筆圧カーブを適用した太さに、ブラシサイズ1個分を基準とする距離のダンピングをかけ、元の太さとダンピング結果の大きい方を採用する。急に細くなった部分はなだらかにつながり、太い部分と筆圧上昇時の太さは保たれる。時間によるダンピングは使わず、ペンを止めたり離したりした後の補正アニメーションは発生しない。

補正は入力の到着順に行い、将来の入力や終端の確定を待たない。以前の双方向の端部補正とは異なり、筆跡の途中でも急な細まりを補う。後から太い入力が来た場合に、それ以前の細い線をさかのぼって太くする処理は行わない。これにより、完成線への切り替えをきっかけとする太さの変化をなくす。Inkの入力予測と増分描画はそのまま使う。

固定幅ペン、筆圧のない入力、蛍光ペン、旧StockBrushesは独自の動作を保つ。既存のカスタム筆圧ペンは再読み込み時に同じ筆圧カーブからこのブラシを再生成するため、保存形式の変更は不要。

実機の自動テストでは、ペンを離す前に細まりが補われること、太い部分の維持、速い筆記・遅い筆記での急な細まりの補完、補正の時間変化がないこと、完成線への受け渡しでの太さ維持（Inkの輪郭丸めを許容）、保存・再読み込みでの画素一致、元の入力の保持、予測入力の取り消しを検査する。手書きの感触や端末全体の入力から表示までの遅延は、これらの描画テストとは別に評価する。
