# コンフリクト一覧

- 同じ内部ノートIDを持ち、内容の異なる `.misq` がある場合だけ、設定ボタンの右に一覧ボタンを表示する。編集画面では左上に配置し、開いているノートの別版だけを対象にする。ノート一覧画面では全ノートの別版を対象にする。
- 内部保存先、選択した外部保存先の `inkdata`（なければ選択フォルダー直下）、未適用の外部変更を検査する。アプリ表示中は約10秒ごとに再確認する。読み取りだけの確認では全画面の処理中表示を出さず、実際に自動取り込みするときだけ操作を保護する。
- ファイル名や同期ツール固有の接尾辞には依存しない。同内容の複製、表示位置・ペン選択・サムネイルだけの違いは重複として扱う。
- 片側だけの追記で、他方の筆跡が内容・順序ともそのまま含まれる場合は、一覧表示前に表示中のノートへ自動取り込みする。強さの設定にかかわらず確認は求めない。別版ファイルと変更前の世代は保持する。既知の削除、両側の追記、筆跡の変更、ノート名・用紙の差はこの自動処理に含めない。編集中は保存完了後に取り込み、ローカルのUndo/Redoと表示位置を維持する。
- 一覧にはノート名・ファイル名・更新日時を表示し、各版の右端のアイコンから別ノートとして開く。マージボタンは一覧右上に1つだけ配置する。複数ノートがある場合は対象ノートを選んでからマージする。「別ノートとして開く」で新しいIDのノートを作成し、名前に「（別版）」を付ける。元のノートと別版の元ファイルは保持する。
- 開いた別版は一覧から外れる。作成したノートを削除した場合や、別版が再更新された場合は再び一覧に表示する。
- 外部の別版はストリームでキャッシュにコピーする。元のファイルは書き換えず、キャッシュはファイルごとに置き換えて過去版を蓄積しない。
- 他ツールが作った未知のUUIDファイル名のコピーを、既存の同期処理の孤立ファイル整理で削除しない。

同期ツールが両方の版を残す運用を前提とする。片方が上書き・削除された場合、この一覧だけでは復元できない。既存の同期・自動マージ・復旧履歴方式を置き換える変更は含めていない。

検証は `NoteConflictsTest`、`MisqArchiveTest` の関連テスト、および独立した検証用ノートを使う `NoteConflictsDeviceTest` で行う。本番アプリや本番ノートをテスト用に変更しない。

通常のノートファイルがなく別版だけ残っている場合は、各版の内部の最終更新日時が最も新しい版を、ノート一覧と紙面に1冊として表示し、一覧に「コンフリクト有」を付ける。同時刻ならノート内容のSHA-256ハッシュの昇順で固定する。表示位置・ペン選択・サムネイルやファイル名はこの順序に影響しない。ファイルの更新日時は採用判断に使わない。閲覧・サムネイル・表示位置やペン選択だけではノートファイルを作らない。筆跡・名前・用紙の保存時に、その版の全履歴を引き継いで同じノートIDで保存し、別版は保持する。保存前に別の通常ファイルが到着した場合は上書きしない。

## 差分の確認とマージ

- 同じノートの未解決の別版が3つまでなら全部を比較対象にする。4つ以上なら先に比較する別版を3つ選ぶ。表示中の版は常に含め、選ばなかった別版は未処理として残す。表示中のノートと選んだ各別版を採用候補にする。比較用のコピーは固定し、最終確定まで元ファイルは更新しない。
- 仮表示中はその最新版を比較の基準とし、残りが3版までなら全部を比較する。残りが4版以上なら3版を選ぶ。1版しか残っていなくても最終プレビューから保存できる。確定前のキャンセルではファイルを作らず、確定時に同じIDで保存する。
- ノート名・用紙の競合は専用の設定画面で先に解決する。ノート名は文字、用紙はプレビューから各版を単独選択でき、名前と用紙で別々の版を選べる。設定だけの競合なら最終確認へ直接進む。筆跡画面の設定から名前・用紙を選び直すこともできる。
- その後は紙面を全面に表示し、筆跡だけを「変更1 / N」から順に確認する。変更一覧と重ね合わせ表示は使わない。
- 今の変更範囲だけ背景を薄い青にし、追加・移動後の線の輪郭を緑、削除・移動前の線の輪郭を赤い破線で示す。画像は外枠で示す。縁取りは筆跡の内側とアンチエイリアスの縁を避け、少し隙間を空けた外側だけを半透明で塗る。
- 表示中のノートと別版3つまでは最大4面で同時比較する。各紙面の上部に更新日時のラベルを置き、仮表示の基準は「最新版 (yyyy-MM-dd hh:mm:ss.SSS)」、別版は「yyyy-MM-dd hh:mm:ss.SSS」で表示する。選択ボタン・チェックボックスは出さず、紙面を単押しして採用を切り替える。選択中は紙面全体を薄い緑で覆い、中央のチェックマーク形だけを抜いて表示する。ドラッグ・拡大縮小・長押しでは採用を切り替えない。変更 x/y は画面下部に表示する。別版が4つ以上の場合は右下で表示する別版を切り替える。各紙面を単押しして採用対象にする。表示中のノートと候補の比較、選択中の結果を切り替えられる。
- 複数採用は同じ筆跡・同じ内容を重複させずに併合する。異なる追記や移動先はそれぞれ残し、候補番号順に重ねる。削除対変更、ノート名、用紙は単独選択にする。
- 画面下部の「戻る矢印・変更 x/y・次へ矢印」に移動を統合する。次へ進むと現在の選択を仮決定し、この時点では保存しない。戻る際も有効な選択は保持する。最初の変更で戻ると比較を閉じる。独立した仮決定ボタンは置かない。
- 全箇所の仮決定後に最終確認画面を出す。全体のプレビューから確認用の背景色・輪郭を外し、大きな紙面に加えて編集画面と共通のサイドプレビューを表示する。全体・星の行の切り替え、表示枠のドラッグ、開閉とハンドルによる幅・位置の調整ができる。プレビュー操作は比較中の表示位置だけを変更し、ノートは保存しない。下部の右側が「保存」に切り替わり、表示中のノートに上書き保存する。左側の矢印で最後の変更へ戻れる。ノートID・作成日時を維持し、選んだ名前・用紙を適用する。上書き前の世代と各版の筆跡履歴・別版ファイルを保持し、今回扱った別版を一覧から外す。比較中に表示中のノートが更新された場合は上書きせずエラーにする。
- 共通履歴と内容ハッシュで変更を判定する。同一内容の筆跡は確認を求めない。端末の時計だけで採用する版を決めない。
- 設定の「手動・慎重・標準・積極的」は候補の初期選択に使う。初期値は慎重。仮決定後は強さを変更せず、各選択は戻って修正できる。
- 同じ変更範囲に他の版から変更がある場合は原則として手動選択し、積極的では追加同士の併合を提案する。履歴や範囲が不明な場合は自動選択しない。
- 拡大縮小と移動は紙面内に制限する。下端は変更前後の筆跡全体に40座標単位を加えた範囲（最低1000）とし、縦長ノートの末尾にも移動できる。
- ファイルはストリームでコピーし、筆跡単位のデコードと上限付きの描画キャッシュを使う。キャンセル時は比較用コピーを削除する。

検証は `StrokeMergePlanTest`、`MultiMergePlanTest`、`MergeViewportTest` と、検証アプリ内の独立したノートを使う `MergeReviewDeviceTest` で行う。
