# 筆跡描画の軽量化と筆記比較（2026-11-07）

## 実装

- 直前の操作中・操作直後の先読み抑制を撤回した。既存の先読み動作に戻して比較した。
- 通常描画と入力中の形状許容誤差を `min(0.1, ペン幅/32)` に変更した。従来は `min(0.01, ペン幅/128)`。細いペンでは幅に比例して誤差を抑える。
- アンチエイリアスと筆圧・リアルタイム補正は維持し、曲線と丸いペン先の細分化を減らした。
- 保存済みの細かい筆跡も表示時に軽量形状へ変換する。元の入力点・筆圧・ノイズシードは変更しない。サムネイル・出力プレビュー・点滅表示にも適用する。
- PNGとPDFの出力では元の入力から従来の高精度形状 `min(0.001, ペン幅/1024)` を再構成する。PNGの通常出力も高品質を既定とした。

## 方法

ユーザー指定により旧版・新版を各1回のみ測定した。Xiaomi Pad 7（Android 16）、検証用applicationId `net.neomenia.misqnotes.probe`。輝度設定71・自動輝度オフ、USB接続。旧版→冷却→新版の順で各12分間。旧版は23℃から開始した。旧版後約18分の画面オフ冷却でもバッテリー温度が25℃で安定していたため、時間短縮のため新版の開始基準を25℃へ変更した。CPU・GPUの開始温度も表に記載し、バッテリー温度の上昇幅は公平な同温度比較と解釈しない。室温センサーは測定しておらず、バッテリー温度とCPU/GPUセンサーで開始状態を確認した。

実際のエディターとローカルFormat 3保存・サムネイル生成を使い、個人ノートと分離した専用領域で3,600本を初期配置した。固定シード61723で長さ・向き・曲率・位置・筆圧を変えたSTYLUS MotionEventを送り、筆跡が蓄積する固定表示領域で連続筆記した。ズーム・スクロールの負荷試験は行っていない。物理ペンやデジタイザ経由の入力、外部ストレージ同期は再現していない。

15秒ごとに温度とプロセスCPUカウンターを採取した。CPU使用率100%は1コア分。CPU/GPU温度は各サンプル時点の最高温度センサー。終盤平均は最後3分。GPU busyは端末全体のサンプル値で、アプリ単独の積算電力や使用率を意味しない。

## 結果

| 指標 | 旧版 | 新版 |
|---|---:|---:|
| バッテリー温度 | 23→30℃ | 25→30℃ |
| 開始CPU温度 | 29.3℃ | 30.1℃ |
| 開始GPU温度 | 28.5℃ | 28.9℃ |
| 平均プロセスCPU使用率 | 152.6% | 146.2% |
| 終盤CPU温度平均 | 76.5℃ | 69.1℃ |
| 終盤GPU温度平均 | 67.0℃ | 64.9℃ |
| 追加した筆跡 | 1,118本 | 1,124本 |
| 計測中の最大thermal status | 0 | 0 |

平均プロセスCPU使用率は約4.2%減った。終盤GPU温度平均は約2.0℃低かったが、終了時のバッテリー温度は両版とも30℃であり、大幅な発熱改善を示す結果ではない。各1回の比較であり、順序や環境の影響を除いた再現性は未確認。温度差をそのまま消費電力の削減率と解釈しない。
