# Misq notes

Xiaomi Pad 7 / Xiaomi Focus Pen向けのKotlin・Jetpack Compose製ノートアプリです。ローカルだけで動作し、通信権限やアカウントを要求しません。

現在のバージョンは `0.1.2`、本番IDは `net.neomenia.misqnotes`、デバッグIDは `net.neomenia.misqnotes.probe` です。アプリ名は日本語・英語ともに `Misq notes` です。

## 機能

- Jetpack Ink 1.0.0による筆圧対応の筆記。RGB各0〜255、太さ1〜50の整数、透明度0〜100%。筆圧と太さのカーブを調整可能。
- 細い筆跡の先端が多角形に見えにくい輪郭精度を使用。既存の筆跡は表示時に必要な分だけ再構築してキャッシュし、保存済みの入力点は維持。PDF・選択範囲のキャプチャーはさらに高精度の輪郭を生成。
- 総合設定 → ノート設定の「筆跡キャッシュ」で、輪郭の保持量を128本・画面内すべて・画面内＋前後1画面・ノート全体から選べます。標準は前後1画面で、画面外は操作の合間に先読みします。スクロール中は描画命令を座標移動で再利用し、画面端の筆跡も欠けずに表示します。
- 蛍光ペン。ペンとは別の色・太さ・透明度を保持し、同じ筆跡内の重なりによる濃淡を抑える。
- 投げ縄による筆跡全体の選択・移動・削除。ツールバー2列目で「自由」「矩形」を切り替え、前回の選択方式を保存。移動と削除も1回のUndoで戻せる。消しゴムと投げ縄の2列目は区切り線なしの中央寄せ。
- 1本指で長押しすると「余白を挿入」を表示。選択後に水平バーと中央の丸いハンドルを表示し、丸を上下にドラッグして余白の高さを調整。指を離しても調整を続けられ、書き始めるか丸以外を指で押すと確定。長押し位置より下の全筆跡を垂直に移動し、境界をまたぐ筆跡も全体を移動。画面外も対象。2本指でキャンセル、調整全体を1回のUndoで元に戻せる。
- 大きさを調整できる円形の消しゴム、操作単位のUndo/Redo。ペン・蛍光ペン・消しゴムにそれぞれ太さテンプレート3枠。
- ラベルなしのフローティングツールバー。Undo/Redo・仕切り線・各ツールを1列にまとめ、右端の丸囲み矢印で折りたたみ。下段でRGBの保存色と太さをワンタップで選択。
- ペンと蛍光ペンの保存色を独立して管理。保存中だけ右下にスピナーを表示。
- ノート画面では時刻などのステータスバーを非表示にし、左上の矢印アイコンで一覧に戻る。
- 下ボタンの一時消しゴム。解放後も同じ接触中は消去を維持し、ペン先を離すと元のツールへ戻る。3つの物理ボタンに操作を割り当て可能。
- 横幅1000の論理座標、縦に連続するノート。
- 指1本で移動、2本で拡大縮小。100%以外では左下に倍率を表示し、倍率変更中は中央にも大きく表示して最終変更から500ミリ秒後にフェードアウトする。表示範囲の筆跡を索引で選んで描画。
- フォルダ階層によるノート整理、グリッド／最大幅840dpのリスト表示、先頭1000×1000論理座標のサムネイル。
- ノートごとの背景色、横罫・カレッジ罫・方眼・ドットと罫線の色・間隔・太さ。新しいノート用の既定値も設定可能。
- 圧縮したベクターデータの自動保存・再読込。表示位置とペン設定もノートごとに保持。
- チェックサム・直前の管理情報による復旧。保存失敗時は編集中の内容を残して再試行。

PDF、画像挿入、ページ方式、外部入出力・バックアップは後続の対象です。Undo/Redoは256操作までで、ノートを開き直すと履歴をリセットします。

## 操作

新しいノートを作るか、一覧からノートを開いて書き始めます。保存ボタンは不要です。指で操作するときは、手のひらによる誤移動を防ぐためペンを画面から少し遠ざけてください。

ツールウィンドウの空いている部分をドラッグすると、上下左右の辺へスナップできます。左右では縦向きに配置し、四隅へ動かすと直径96dpの丸いボタンに最小化し、画面端から12dp離します。左上隅は戻るボタン群の下へ置きます。押すと、直前の展開先が隣接する辺ならその辺へ、そうでなければ隣接する上辺または下辺へ開きます。展開先の辺では中央に寄せ、端から8dp離します。スワイプで別の位置へ移せます。点6つのつまみを取り除き、上段は左からUndo・Redo・仕切り線・ペン・蛍光ペン・消しゴム・投げ縄を1列に配置します。道具のアイコンを長押ししてスワイプすると、半透明のアイコンが指に追従して順序を変えられ、再起動後も保持します。丸囲み矢印は横配置では常に右端、左右の縦配置では常に下端へ固定し、収納・展開する方向へ向けます。スナップ時には位置とサイズをアニメーションさせ、ドラッグ中は指に追従します。左上の操作群と重なる場合だけ位置を避けます。左右配置でも色の領域だけをスクロールし、太さ3枠を固定します。影はサイズアニメーションの外側で描きます。選択中の道具は背景色で表示し、ペン・蛍光ペン・消しゴムをもう一度押すと詳細設定が開きます。基本のアイコンボタン・保存色・太さ枠・作成ボタンは円形にし、押したときの表示も背景の形に収めます。「適用」と「変更を破棄」は文字で表示します。

ツールボックスのカラフルなパレット、または詳細設定のパレットアイコンからカラーピッカーを開きます。左側の彩度・明度の正方形とその下の色相バーで選ぶか、右側のR・G・B（対応画面はAも）各0〜255とHEXで入力し、「適用」で確定し、「変更を破棄」で取り消します。保存アイコンで色を登録でき、ペンと蛍光ペンで別々の保存色を持ちます。各道具の登録色はノート間で共有され、再起動後も残ります。従来の共有パレットは移行時に両方へ引き継ぎ、その後は片方の追加・削除がもう片方へ影響しません。色画面で登録色を選び、ごみ箱アイコンで削除できます。ウィンドウ下段の左側の丸をタップするとすぐに選べ、透明度はそのまま保ちます。

太さは1〜50の整数、透明度は0〜100%を詳細設定のスライダーで指定し、横に整数値だけを表示します。数値入力欄や目盛りの点はありません。直前の太さ10を新1、直前の50を新40に合わせ、細い側ほど段階を細かくしています。既存の筆跡の太さは変更しません。透明度0%は不透明、100%は完全透明です。太さ・透明度・色相のバーは一定幅の角丸の太線で、つまみと同じトラック内に描きます。透明度は市松模様の上に現在色が左から右へ薄くなるグラデーションで表示します。

筆圧と太さのグラフは、ノート一覧の歯車アイコンから「総合設定」→「ペン設定」→「筆圧と強さ」を押して開きます。ポップアップにはタイトルと正方形のグラフだけを表示します。総合設定は「外観」「ペン設定」「ノート設定」に分かれ、一覧の表示形式と並び順はノート一覧で変更します。グラフの説明文や選択点の数値詳細は表示しません。正方形のグラフで横軸が筆圧、縦軸が太さです。空白のタップで通過点を追加し、ドラッグで移動できます。曲線は全ての点を滑らかにつなぐ通過点式のベジェ曲線です。選択点には四角いハンドルを表示し、ドラッグで接線の方向と長さを調整できます。左右の方向は連動し、長さは別々に調整します。太さの逆転を防ぐ範囲でハンドルを制限し、ハンドルのドラッグでは点を削除しません。点とハンドルは再起動後も復元します。少しはみ出しても点を残して端へ寄せ、正方形から十分離れたときだけ削除します。削除判定には外側へ72dpまたはグラフの一辺の20%の大きい方だけ猶予を設け、その範囲内なら押したまま戻して調整できます。削除した同じドラッグ中には別の点を動かしません。強く押すほど細くなる反転や範囲外への飛び出しを防ぎ、両端は維持します。右上の最大点は固定し、左端の点を上下に動かして最低太さを調整します。100%にすると一定幅になり、左端の点を下げれば再び太さを変化させられます。スライダーは表示しません。変更は全ノートで新しく描くペンに適用し、保存済みの筆跡は維持します。蛍光ペンは筆圧によらず一定の太さです。

太さテンプレートはペン・蛍光ペン・消しゴムにそれぞれ3枠あり、ノート間で共有し再起動後も残ります。ツールボックスの枠をタップすると呼び出し、選択中の枠をもう一度タップすると専用の編集画面が開きます。道具の詳細設定にはテンプレート編集を置きません。消しゴムの大きさは円の直径1〜50で、下ボタンの一時消しゴムにも同じ設定を使います。円が触れた筆跡全体を消し、高速な移動でも円の通過範囲を判定します。

投げ縄はペンで囲んだ領域内、またはその境界と交差する筆跡全体を選択します。選択枠の中はペン・指でドラッグして移動でき、選択範囲の近くに表示するフローティングパネルのごみ箱で削除、閉じるアイコンで選択解除できます。選択中に道具を切り替えても選択は残ります。範囲外に触れると選択を解除し、その接触から選択中の道具による描画・消去・新しい投げ縄、または指による画面移動を始めます。パネルは画面の移動に追従し、拡大縮小すると選択範囲とパネルを解除します。移動・削除はそれぞれ1回のUndoで戻せ、移動後も重なり順と筆圧などの情報を保って保存します。

画面左上に戻る矢印とノート背景のアイコンを並べ、共通の背景で一体表示します。戻る矢印は1回で一覧へ戻ります。OSの戻る操作は1回目に「もう一度戻るとノート一覧へ戻ります」と短く案内し、2秒以内の2回目で一覧へ戻ります。時間が空くと1回目として扱います。ノート画面ではシステムのステータスバーを隠し、一覧では元に戻します。下部のタイトルと保存状態の文字は表示せず、ノート・色・太さ設定の保存中だけ右下にスピナーを表示します。拡大率は初期100%、最大600%です。左下は100%のとき非表示にし、それ以外ではピンチ中も更新します。倍率が変わると中央へ大きく表示し、半透明の背景で最後の変更から500ミリ秒保持し、200ミリ秒でフェードアウトします。ノートを開き直すだけでは中央の表示を出しません。

下ボタンはペン先を浮かせた状態で押し、保持したまま接触させると消しゴムになります。2026-10-16の指定変更により、ボタンを解放しても同じ接触中は消去を続けます。ペン先を離すと元のツールへ戻り、接触中にペン線へ切り替えません。総合設定のペン設定から、下ボタン・上ボタン・独立ボタンそれぞれに、一時消しゴム・各ツール・Undo/Redo・100%表示への復帰・割り当てなしを設定できます。初期は下ボタンが一時消しゴム、他2つは割り当てなしです。

[本番用MVPの確認手順](docs/production-validation.md)で、最初に短いノートを使って再起動後の復元を確認してください。新しく加えた保存・指操作の実機検証結果はまだ未確認です。

ノート一覧の右下の＋で現在のフォルダへノートを作成し、＋を長押しして出るメニューからフォルダを作れます。縦三点メニューからノートの名前変更・削除、フォルダの名前・色の変更と空フォルダの削除を行えます。ノートを長押ししてドラッグすると任意順に並べ替えでき、フォルダ上へドロップすると移動します。フォルダ内からは上に戻る矢印へドロップして親へ移動できます。端へ近づけると自動スクロールします。グリッドのフォルダはタブ付きのフォルダ形状で表示します。右上のアイコンでグリッド／リストを切り替え、ソートメニューで名前・作成日・更新日・任意順を選び、メニュー最上段の矢印アイコン付き「昇順／降順」を押して方向を切り替えます。任意順では最上段を「任意順」と表示し、方向切り替えを無効にします。並び順と任意の順序はルートとフォルダごとに保存します。作成・更新時刻はそれぞれのアイコンを添えた2行で、端末のタイムゾーンの`yyyy-MM-dd HH:mm:ss`（24時間制）で表示し、筆跡件数は表示しません。先頭の論理座標(0,0)〜(1000,1000)を正方形サムネイルに使い、背景色と筆跡だけを描き、罫線・ドットを除外します。

ノート内メニューの「写真を取り込む」「PDFを取り込む」から画像やPDFを追加できます。既存の内容の下へ配置し、PDFは全ページを縦に並べます。写真は向きを反映した画像、PDFはページごとの画像としてノートへ埋め込むため、取り込み完了後に元ファイルを削除しても再表示できます。上からの書き込み、全体を囲む投げ縄での移動・複製・削除、取り込み全体のUndo/Redo、PNG/PDF出力、保存先への同期・バックアップ復元に対応します。消しゴムは手書き線だけを消します。入力は256MBまで、PDFは200ページまで、取り込み1回あたりの画像データは64MBまでです。描画用画像は長辺を写真2048px、PDFは原則幅2000pxに調整し、1ページ400万画素以内で保存します。

ノート左上の戻る矢印の右隣の用紙アイコンで、そのノートの背景色・罫線を変更できます。ドット・罫線の太さは従来の太さを1として0.25〜8の範囲で指定できます。罫線の色はRGBA各0〜255で指定でき、A=0で非表示、A=255で不透明です。背景色は不透明のままです。カレッジ罫は横罫に左側の縦罫線を加えた用紙で、縦線のRGBA色・太さ（0.25〜8倍）・左端からの距離（0〜1000論理座標、用紙幅1000）をそれぞれ変更できます。総合設定の「ノート設定」は新しく作るノートの背景を指定します。キャンバスには縦・横（拡大時）のスクロールバーを表示し、一覧・設定・色と道具の詳細にもスクロール位置を表示します。縦に連続するキャンバスでは、筆跡の最下端と現在表示範囲を基準にバーを伸ばします。

最初の筆記に備え、画面生成時にInkの`eagerInit()`で描画リソースを準備します。初回ストロークの遅延改善幅は実機未計測です。

## ビルド

Android Studioで開き、JDK 17、Android SDK Platform 35、Build Tools 35.0.0を使用します。初回の依存取得には開発PCの通信が必要です。

```powershell
.\gradlew.bat :app:assembleRelease :app:assembleDebug :app:testDebugUnitTest :app:lintRelease
```

- 本番署名付きAPK：`app/build/outputs/apk/release/app-release.apk`
- デバッグAPK：`app/build/outputs/apk/debug/app-debug.apk`
- 実機自動テスト：`.\gradlew.bat :app:connectedDebugAndroidTest`

本番署名の更新に必要なローカル鍵・設定は `.signing` に保管しています。既存アプリの更新を継続するため保管し、Gitには追加しません。鍵がない環境ではrelease APKは未署名になるため、配布前に署名を用意してください。

Gradle 8.11.1 / AGP 8.9.2 / Kotlin 2.1.20 / Compose BOM 2025.04.01 / Ink 1.0.0 / MotionPrediction 1.0.0を固定しています。

## データ

保存先は未指定が既定で、アプリ内部の `filesDir/notes` にノートごとの管理情報と圧縮入力点を保存します。「総合設定 → ノート設定 → ノートの保存先」でフォルダを指定すると、ノート管理情報を `notes/manifests`、筆跡を `notes/strokes`、フォルダ構成を `settings/folders`、用紙・罫線の既定値、カラーパレットと太さテンプレートを `settings/presets`、保存履歴を `history` に分けます。旧版の直下保存や `Handwriting Notes` からも読み込み、内容確認後に新しい階層へ整理します。テーマや物理ボタンの割り当てはアプリ内に残します。現在のデータを引き継いで切り替え、「デフォルトに戻す」でも引き継ぎます。既存データがある保存先は、手元にノートもフォルダもないときに開きます。手元と同じデータなら再指定でき、異なるデータは上書きしません。

指定時も描画のための作業コピーはアプリ内に置き、指定先での保存を確認してから保存完了とします。通常の画面遷移では書き込みを待ちます。保存中の強制終了では直近の未保存操作が失われる可能性があります。アプリの削除・データ消去ではアプリ内のデータを失います。指定先のデータは残り、再び同じフォルダを選ぶと復元できます。

新規ノート・フォルダと名前変更の入力欄は空で開き、空のまま適用すると「無題」「新しいフォルダ」にします。入力前はプレースホルダーで既定名を示します。

ノート左上の設定ボタンから見出しのない設定ポップオーバーを開き、背景設定の行から画面中央の背景設定ウィンドウへ進みます。同じポップオーバーのPDF文書・写真のアイコンで保存先を選んでPDF・PNGへエクスポートできます。ポップオーバーは約140msで拡大・フェード表示／縮小・フェード消去します。一覧の縦三点メニューからも出力できます。PDFは用紙色と筆跡だけを出力し、罫線・ドットを省きます。横方向に筆跡のない境界で改ページし、切れ目のない筆跡の範囲がページを超える場合に分割します。PNGはノート全体を1枚にし、長いノートは画像サイズの上限に合わせて縮小します。

投げ縄の選択パネルには筆跡複製・PNGキャプチャー・削除・解除を横並びに置きます。コピーマークを押すとその場で複製し、1回のUndoで戻せます。貼り付け操作はありません。キャプチャーは選択した筆跡の外接範囲を用紙色と罫線付きのPNGにしてクリップボードへコピーします。右上に「クリップボードにコピーしました」と共有アイコンのスナックバーを約3秒表示し、左右のスワイプでも閉じられ、上下には動きません。背景・文字・共有アイコンの配色を現在のテーマに合わせます。共有表示の設定は廃止しました。

Phase 1の診断Activityはdebugビルドにだけ含めています。本番版は入力ログを記録しません。

総合設定の「ペン設定」に「ペンのシステムジェスチャーを抑制」を用意します。初期状態はオフです。オンではペンのホバー・接触中にノートのOS戻るを無視し、ペン付近の左右端で戻るジェスチャーの除外範囲を指定します。ペンを離すと解除します。ホームなどOSが必須とする操作は完全には無効化できません。

RGBAの罫線は背景色と合成します。半透明の方眼では、横線と縦線が重なる交点が少し濃く見えます。

色選択ウィンドウは小さくし、右側に丸い色サンプル、RGB(A)、HEX入力をまとめます。HEXは #RGB / #RRGGBB、透明度対応画面では #RGBA / #RRGGBBAA（Aは末尾）も受け付けます。ノート内では丸いプレビューの背景だけをノートの背景色に合わせ、ウィンドウ自体は通常の背景を使います。フォルダ色は15色の小さなパレットから即時選択し、カラフルなフリーボタンからだけカラーピッカーを開きます。

総合設定の内容は中央寄せ・最大幅720dpです。「外観」のプルダウンから、端末に合わせる・ライト・ダークを選べます。独立したAMOLEDスイッチをオンにすると、ダーク表示時の画面背景を #000000 にします。スイッチはライト選択時だけ非表示になり、オン・オフの状態は保持します。一覧・設定・ツール・ダイアログへ共通のテーマを適用し、ノート設定の用紙プレビューもその範囲だけに描画します。ノート用紙と筆跡は保存した色で表示します。テーマとAMOLEDは再起動後も保持し、従来の有機EL設定はダーク＋AMOLEDへ引き継ぎます。ステータスバーとナビゲーションバーのアイコンも明暗を合わせます。「筆圧と強さ」は右端の矢印が付いた設定行からポップアップを開きます。

ノートの設定、ペン・蛍光ペン・消しゴムの詳細、太さテンプレートはボタン付近の小さいポップオーバーで開きます。ノートの背景設定は画面中央のウィンドウで開きます。基本幅320dp、色選択380dpを上限とし、画面外やキーボードを避けます。物理ボタンには「一時投げ縄」も割り当てられます。選択できなかった場合はボタンの解放とペン先の離脱の両方を待って元の道具へ戻ります。選択範囲がある間は、ボタンを解放しても範囲内をペン・指で移動できます。範囲外に触れた時点で元の道具・指の操作へ戻り、その接触も操作に使います。範囲外への接触時にボタンがまだ押されていても、離して再度押すまで一時投げ縄を再開しません。

「総合設定 → 言語」から「端末に合わせる」「日本語」「English」を選べます。一覧・設定・ツール・ダイアログ・通知と読み上げラベルを日本語／英語で用意し、選択は再起動後も保持します。端末に合わせる場合、英語の端末では英語、それ以外の未対応言語では日本語を使います。既存のノート名・フォルダ名と筆記内容は変更しません。言語設定は端末内に保持し、ノートの外部保存先には含めません。PDF出力のアイコンは三角形のループ形状です。
